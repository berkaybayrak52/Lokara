# Wording Leerstandsaufstellung

Betrag / Satz: Die Leerstandsaufstellung darf NIE als „gesetzlich vorgeschrieben" vermarktet werden — korrektes Wording: „erfüllt Ihre Nachweispflicht gegenüber dem Finanzamt". Ebenso durchgängig „rechtskonform", nie „rechtssicher". Die Aufstellung ist eine freiwillige Form zum Nachweis der fortbestehenden Einkünfteerzielungsabsicht.
